A web-based community resource directory built for the Community Action Partnership of Kern (CAPK) 2-1-1 program. The platform helps Kern County residents find local services and support including food assistance, housing, health care, utilities, and more. The project is being built as a modern replacement for the current iCarol-hosted system, with a focus on mobile responsiveness and WCAG 2.1 AA accessibility compliance.

The platform includes a public-facing resource directory with an interactive map and a staff-facing portal for agency managers and CAPK administrators to manage listings.
