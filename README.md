# CAPK 2-1-1 Community Resource Directory

A web-based community resource directory built for CAPK 2-1-1 to help Kern County residents find local services and support. Users can search and browse resources such as food banks, housing assistance, mental health services, and more. The platform also includes an admin interface for managing resource listings.
